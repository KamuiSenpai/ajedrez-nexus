# Feedback / Comentarios

## English

This repository presents Ajedrez Nexus; the application source is not included. Contributions here are product feedback, reproducible problem reports and corrections to the presentation.

- Use the [issue templates](https://github.com/KamuiSenpai/ajedrez-nexus/issues/new/choose) and describe the task you were trying to complete.
- For a problem, include the relevant screen, steps, expected result, actual result, platform and browser. Attach a screenshot only after removing private information.
- For a suggestion, explain the user need and how the change would improve study or teaching.
- Do not upload credentials, student data, proprietary databases, copyrighted course material or application source code.
- Send private or security-related information through [email](CONTACT.md), not an issue.

## Español

Este repositorio presenta Ajedrez Nexus; no contiene el código de la aplicación. Aquí puedes aportar comentarios sobre el producto, problemas reproducibles y correcciones de la presentación.

- Usa las [plantillas de incidencias](https://github.com/KamuiSenpai/ajedrez-nexus/issues/new/choose) y explica qué intentabas hacer.
- Para un problema, indica la pantalla, los pasos, el resultado esperado, lo ocurrido, la plataforma y el navegador. Adjunta capturas sólo después de retirar información privada.
- Para una propuesta, explica la necesidad del usuario y cómo mejoraría el estudio o la enseñanza.
- No subas credenciales, datos de alumnos, bases privadas, material de cursos protegido ni código de la aplicación.
- Envía los temas privados o de seguridad por [correo](CONTACT.md), no mediante una incidencia.
