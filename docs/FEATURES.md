## English

The screenshots illustrate these areas; one image is not intended to represent every action in a module. This catalog describes existing local workflows, not a downloadable feature bundle or a new full-system certification.

| Workspace | Functions and purpose |
| --- | --- |
| **Home** | A daily tactical position, champion-game playback with manual or automatic navigation, a rotating tournament highlight, news cards and a ranking panel. External content follows source availability. |
| **Preparation** | Compare the library and two players at the same position and chosen colors; inspect separate game lists and win/draw/loss statistics; use game tabs, working copies, notation, local saves and a pinnable Stockfish analysis. [Current walkthrough](UPDATES.md#english). |
| **Opening explorer** | Follow continuations from a position; compare game counts, score, draws, years and usage indicators; inspect variations and games; filter a local library. |
| **Study editor** | Create or import PGN studies; navigate main lines and variations; annotate moves with comments and symbols; add chapters and board markings; save studies and export PGN. |
| **Engine analysis** | Inspect Stockfish evaluations and principal variations; adjust analysis options; pin analysis to a position, navigate elsewhere, return to the anchor or resume following the board. |
| **Document and image export** | Export annotated studies to PDF or standalone HTML, with diagrams and variations; use board image/GIF export for visual sharing. A rendered demonstration PDF page is retained in the [historical gallery](archive/GALLERY-2026-11-18.md). |
| **Introductory learning** | Follow lessons about pieces and rules, read illustrated prompts, move on the board, request a hint and resume saved progress. |
| **Opening repertoire & review** | Learn opening lines step by step, work toward learning goals, review remembered lines and see lesson/rank feedback. |
| **Tactics** | Solve exercises, request hints, inspect the source game, review mistakes and follow training plans, reviews and a local progress profile. Nexus training ratings are distinct from official FIDE ratings. |
| **Endgames** | Practice guided positions with concrete goals, method/hint guidance, position reset and progression along a learning route. |
| **Strategy** | Browse themed positions, record your own line, compare analysis modes, organize a study session and search similar positions. Some modes depend on configured services or available data. |
| **Coach** | Use the board and study context to ask about a position, threat or plan; review games with the engine. New AI explanations need a configured provider; engine review and AI conversation are separate functions. |
| **Live tournaments** | Browse current, upcoming and completed events; open rounds, boards and games; inspect moves and standings where provided; navigate history and return to the live position. Source availability governs coverage. |
| **Settings & accessibility** | Choose board colors and piece styles, adjust text size and contrast, control training sounds and header behavior; manage library selection, updates and explorer filters. |
| **Learning feedback** | Saved progress, completed-lesson summaries, review feedback, study ranks and streaks connect individual sessions to a longer learning journey. |

## Español

Las capturas ilustran estas áreas; una imagen no pretende representar cada acción del módulo. El catálogo describe flujos locales existentes, no un paquete descargable ni una nueva certificación integral.

| Espacio | Funciones y propósito |
| --- | --- |
| **Inicio** | Táctica del día, reproducción manual o automática de partidas de campeones, carrusel de torneos, noticias y clasificación. Los contenidos externos dependen de sus fuentes. |
| **Preparación** | Comparar biblioteca y dos jugadores en la misma posición y con colores elegidos; consultar listas y estadísticas de victorias/tablas/derrotas; usar pestañas, copias de trabajo, notación, guardados locales y análisis Stockfish fijable. [Recorrido actual](UPDATES.md#español). |
| **Explorador de aperturas** | Seguir continuaciones desde una posición; comparar partidas, puntuación, tablas, años e indicadores de uso; consultar variantes y partidas; filtrar la biblioteca local. |
| **Editor de estudios** | Crear o importar PGN, navegar líneas y variantes, añadir comentarios y símbolos, organizar capítulos y marcas del tablero, guardar estudios y exportar PGN. |
| **Análisis de motor** | Consultar evaluaciones y variantes de Stockfish, ajustar opciones, fijar una posición mientras se navega, volver al ancla y recuperar el seguimiento del tablero. |
| **Documentos e imágenes** | Exportar estudios comentados a PDF o HTML autónomo con diagramas y variantes; generar imágenes/GIF del tablero. El [archivo histórico](archive/GALLERY-2026-11-18.md) conserva una página PDF de demostración renderizada. |
| **Iniciación** | Seguir lecciones de piezas y reglas, leer consignas ilustradas, mover en el tablero, pedir una pista y retomar el avance guardado. |
| **Repertorio y repaso** | Aprender líneas de apertura paso a paso, trabajar metas, repasar variantes recordadas y consultar el resultado de lecciones y rangos. |
| **Táctica** | Resolver ejercicios, pedir pistas, consultar la partida de origen, revisar errores, planes, repasos y progreso de un perfil local. La puntuación de entrenamiento Nexus no es el Elo oficial FIDE. |
| **Finales** | Practicar posiciones con objetivos concretos, método y pistas, reinicio de posición y avance por una ruta de aprendizaje. |
| **Estrategia** | Explorar posiciones por temas, registrar una línea propia, comparar modos de análisis, organizar sesiones y buscar posiciones similares. Algunos modos requieren servicios configurados o datos disponibles. |
| **Entrenador** | Preguntar sobre una posición, amenaza o plan usando el contexto del tablero y revisar partidas con el motor. Las explicaciones nuevas con IA requieren un proveedor configurado; revisión de motor y conversación son funciones distintas. |
| **En vivo** | Consultar eventos en curso, próximos y terminados; abrir rondas, tableros y partidas; revisar jugadas y clasificación cuando la fuente las facilita; navegar el historial y volver al directo. La cobertura depende de las fuentes. |
| **Configuración y accesibilidad** | Elegir colores y piezas, ajustar tamaño de texto y contraste, sonidos y cabecera; gestionar selección de biblioteca, actualizaciones y filtros del Explorador. |
| **Progreso y logros** | Avance guardado, resumen de lecciones, resultados de repasos, rangos de estudio y rachas para dar continuidad al aprendizaje. |
